# Screenshots

Drop the following images into this folder (exact filenames matter —
they're already referenced in the main `README.md`):

| Filename | What to capture |
|---|---|
| `home.png` | The Home tab: hero section + the 6 mode cards |
| `diagnose.png` | Mid-diagnosis: a probe question with feedback shown |
| `galaxy.png` | The 3D Concept Galaxy on the Progress tab — ideally with ⚡ Energy Flow or 🌫 Fog of War toggled on, and a node's summary card open |
| `bughunt.png` | A Bug Hunt code snippet with a guess submitted and feedback shown |
| `teachback.png` | A Teach-Back explanation submitted, with grading feedback visible |
| `profile.png` | The Profile tab showing points, badges, and streak |

Once added, the main README's screenshot grid will render them
automatically — no other changes needed.

Tips for good screenshots:
- Use the live demo (or `npm run dev` locally) at a reasonably wide
  browser width (~1280px+) so the layout isn't squished.
- For `galaxy.png`, master a couple of concepts first (via Diagnose or
  Teach-Back) so the galaxy isn't just a grid of gray unseen nodes.
- PNG or JPG both work; keep each file under ~500KB if possible so the
  README loads fast on GitHub.
